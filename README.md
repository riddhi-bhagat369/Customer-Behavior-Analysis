# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes customer shopping behavior data to help a retail company understand purchasing patterns, customer preferences, and factors influencing repeat purchases.

The objective is to answer the business question:

> How can the company leverage consumer shopping data to identify trends, improve customer engagement, and optimize marketing and product strategies? 

The project combines Python for data preparation, SQL for business analysis, and Power BI for visualization and stakeholder reporting. 

---

## Business Problem

A leading retail company observed changes in customer purchasing behavior across:

* Demographics
* Product categories
* Shopping preferences
* Discounts and promotions
* Subscription programs
* Payment methods
* Seasonal trends

The company wants to uncover actionable insights that can improve:

* Customer satisfaction
* Customer retention
* Marketing effectiveness
* Product strategy
* Revenue growth

## Data Preparation (Python)

The dataset was cleaned and transformed using Python.

### Data Cleaning

* Checked data types and dataset structure
* Identified missing values
* Filled missing Review Ratings using category-wise median values
* Standardized column names using snake_case formatting

### Feature Engineering

Created new analytical features:

#### Age Group Segmentation

Customers were grouped into:

* Young Adult
* Adult
* Middle-aged
* Senior

#### Purchase Frequency Days

Converted purchase frequency labels into numerical values.

Example:

| Frequency | Days |
| --------- | ---- |
| Weekly    | 7    |
| Monthly   | 30   |
| Quarterly | 90   |
| Annually  | 365  |

## Key Business Insights

Some important insights generated from the analysis include:

* High-value customers can be identified through purchase history.
* Subscription programs influence customer spending behavior.
* Certain products receive consistently higher ratings.
* Discounts impact purchasing decisions differently across product categories.
* Repeat buyers contribute significantly to overall revenue.
* Customer demographics influence purchasing patterns.
